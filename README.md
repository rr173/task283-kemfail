# 后量子密钥封装失败模式归因服务（kemfail）

密码工程师用本服务区分一批解封装失败是密文损坏、参数版本错配还是硬件噪声集中爆发。服务接收失败摘要、参数集和设备状态，校验参数谱系、归并失败指纹并评分来源候选，工程师可隔离设备、锁定参数基准并发布诊断快照。

## 业务闭环

1. 注册参数集（首个自动成为基线，后续沿 ParentID 构成谱系）与硬件设备。
2. 接收失败事件：64 位 hex 密文摘要 + 失败码；按 run+param+device+digest 前缀构造幂等键，重复写入被拒绝。
3. 接收期预分类：参数摘要与库不一致 → param_conflict；设备噪声高且事件多 → noise_related。
4. 指纹归并：同参数 + 同失败码 + 同密文前缀折叠为指纹，识别批量爆发。
5. 全量归因：密文/参数/设备三路独立评分，最高分落到事件状态并生成来源候选。
6. 工程师确认/否决候选、隔离高噪声设备、发布诊断快照（固定参数基线，发布后冻结）。
7. 运行可封存；封存后所有写入被拒绝，快照可被新版本替代。

## 运行

```bash
CGO_ENABLED=0 GOTOOLCHAIN=local go run ./cmd/kemfail --addr :8080 --db kemfail.db
```

自检：`go run ./cmd/kemfail --smoke-test`
